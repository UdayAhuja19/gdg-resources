PARTY

UP TO 5 PLAYERS JOIN ON THEIR PHONES BY SCANNING A QR CODE, THEN BATTLE ON ONE BIG SCREEN.

GAME 1

MASH BATTLE

Every tap fills your bar, and it drains when you stop. First to fill it wins. If time runs out, the fullest bar wins.

GAME 2

LIGHTS OUT

The F1 start: five red lights come on, then go out after a random hold. Tap as fast as you can; jump the start and it costs you. Fastest total over 3 starts wins.

GAME 3

SPLIT SECOND

The stopwatch trend: 3 rounds, a target of 1–5 seconds each. Start and stop a hidden clock as often as you like in 30 seconds, then lock one time in. The big screen shows everyone's clocks; lowest total error wins.

WHY IT'S NOT ONLINE

The phones and the big screen talk live through a small server on the booth laptop, and GitHub Pages can only host plain pages. So Party runs from the laptop at the event, not from this website. The code lives in the arcade repo.

<SETUP GUIDE> <TEAM HANDOFF>

RUN IT AT THE BOOTH

  1. On the booth laptop, get the arcade code and install it once (needs Node 22.9 or newer). 
    git clone https://github.com/UdayAhuja19/gdg-arcade.git
cd gdg-arcade
npm install
  2. Install the free Cloudflare tunnel once. No account needed. 
    brew install cloudflared
  3. Start Party. The tunnel gives the phones a public link, so they can join on any Wi-Fi or on mobile data. 
    npm run party
  4. Open http://localhost:3101 on the big screen. Players scan the QR code with their phones and type a name.
  5. Pick MASH BATTLE, LIGHTS OUT or SPLIT SECOND under NEXT GAME, press START, and use PLAY AGAIN or BACK TO LOBBY between rounds.

PROTOTYPE, RUNNING THROUGH A CLOUDFLARE TUNNEL. TRY IT WITH REAL PHONES BEFORE AN EVENT.
